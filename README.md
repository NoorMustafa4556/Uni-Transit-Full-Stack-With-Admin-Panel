# Uni-Transit Full-Stack Transit Management System

Comprehensive university transit solution containing both the student mobile app and the administration management portal.

## Project Structure

- **`Uni-Transit-App-Flutter-Smart-Uni-Bus-Tracking-App-main/`**: Cross-platform Flutter Mobile Application for students and passengers (live bus tracking, routes, and notifications).
- **`unitransit_admin_panel-main/`**: Flutter Web Admin Panel for university transit authorities (fleet management, driver dispatch, route planning, stops, and schedules).

## Tech Stack
- **Frontend / Client**: Flutter (Dart)
- **Architecture**: Clean MVC / MVVM
- **State Management**: Provider / Riverpod / ChangeNotifier
